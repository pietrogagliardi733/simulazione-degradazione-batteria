### simulazione-degradazione-batteria

script in python che simula la degradazione della batteria in dei carrelli ospedalieri nell'arco di 30 mesi per poi mostrare una visualizzazione di ciò che accade.
Il file è un'appendice tecnica di un report scritto per la squadra corsa dell'Università di Pisa **E-team** divisione Business Plan ed è comprensivo di una spiegazione dettagliata di come funziona il codice.
Questa non vuole in alcun modo essere una simulazione realistica della degradazione chimica delle batterie utilizzate in apparecchi sanitari, ma è solo a scopo esplicativo
